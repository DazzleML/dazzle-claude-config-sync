## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.**

Specific to this backend: every test here runs against a stdlib fake on an ephemeral port. That fake only knows what the real server has taught it, and twice already it was wrong -- it answered `/api/v0/models` as if it were the OpenAI listing, and it did not model the downloaded-versus-loaded distinction at all. Both gaps were found by running against a real LM Studio, not by testing. **A full end-to-end run against a real server remains unperformed** (the machine's model is loaded with a 197,120-token window and does not answer a merge prompt inside two minutes), so nothing here should be read as evidence that a local model completes a merge.
