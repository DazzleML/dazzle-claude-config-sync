# Mutation sweep: the block with the hunk is the answer (unit U8.2 of the deep-merge slice, #64)

The uncommitted 0.6.9 unit under review: the no-tools capture in `deep_step` now takes the LAST diff block WITH a hunk line (`hunked[-1]`), not the last block outright; an empty diff block still wins as "nothing to change"; a snippet block (content, no hunk) with the model's own json declaring edits is a refusal that names the missing region, while a snippet with no edits declared stays "nothing to change". This sweep is diff-scoped to that one block in `aideep.py` (the `blocks`/`hunked`/`empty` selection and the `elif reasons and not empty` refusal). The paired `tests/test_golden_ai_deep.py` change (`_form_of` reading the answer form off the backend's capabilities instead of the report text) is test-instrument code, not production behaviour, and is out of this sweep's scope by the harness's own rule (test files are never mutation targets).

## Why no round 2

The skill's refinement-round trigger (>=1 killable survivor) is conditioned on feeding the new assertions back into a second generate+sweep round. Since writing those assertions was explicitly out of scope for this run, a round 2 would re-run the same 8 mutants against an unchanged suite and reproduce the identical result -- not a real refinement round, so it was skipped rather than performed as theatre (same reasoning as the 0.6.8 report's "Why no round 2").

## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** This sweep additionally is self-check generation (see above): its 6/8 kill rate should be read as "the specific ideas this diff invited are covered, bar two ordering/detector edge cases," not as an independent measure of suite strength the way a fresh-context sweep's score would be. `equivalents.md` was not written to by this run, consistent with the self-check restriction; if a future round triages M2 or M3 as equivalent rather than killable, that determination belongs to a separated-generation run, not this one.
