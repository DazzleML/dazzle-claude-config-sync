## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.**

The copy rule this sweep covers was itself found wrong by hand two hours earlier, by walking the human checklist's own world (`tests/one-offs/thinking/build_ai_world.py`): every mutant of the old rule was killed too, because the tests agreed with the code about a flow nobody had run end to end. Mutation testing measures the suite against the code; it cannot measure either against the person using them.
