# Mutation sweep: the deep golden set (unit U6 of the deep-merge slice, #64)

The question this sweep answers is different from the four before it. U6 adds no production code, so a diff-scoped sweep over its diff would mutate nothing. Instead the mutants land in the production code the golden set FENCES -- the rung classifier, the deep step's capture and verdict, the report's deep branches -- and the killer is `tests/test_golden_ai_deep.py` alone. A survivor here means the golden set would not notice that defect; whether some other test would is measured separately, never assumed.

## What the sweep says about the golden set

The five first-round kills are the ones a golden set should own: the rungs of a neighbour and a far file, one-sided changes as anchors, the empty-diff path of the no-tools form, the verdict gate's boundary, and the report naming the region. The three fixture fixes are all about the report's fidelity rather than the variant's bytes: which form answered, and whether the model's reason lands on the right edit. That is the right place for a golden set to be strict, because the report is what the person reads before `--accept`.

Two of the survivors that the classifier's own tests cover (M01, M03) are boundary cases no realistic fixture reaches; the golden set does not need to duplicate them, and the coverage measurement shows they are held.

## Restore and verification

- Every mutant's restore byte-verified by the harness in every run; the three production files show no diff after the sweep (`git status --porcelain` on them is empty).
- The full suite ran green after the golden set landed (1138 passed / 23 skipped) and runs once more after the triage edits for the count that ships.
- The generator's blast-radius read: every mutated line is a pure classification, a capture branch confined to the sandbox under `tmp_path`, or a print; no guard in scope prevents a delete, a write outside the sandbox, a network call or a spawned process.

## Caveats

A kill proves the suite noticed *this* change, not that it tests the right thing -- and **a clean sweep is evidence about the mutations tried, not proof of suite completeness.** The golden set's fixtures are one right answer each; a real model that fixes b() another valid way is judged by the person, not by this sweep.
